# EXPALSA | Documentos privados de capacitación

Los 11 PDF del programa **no deben subirse a este repositorio público**, ni como archivos individuales ni dentro de un ZIP. GitHub Pages publica sus archivos sin exigir la autenticación de Firebase.

La aplicación `capacitacion.html` ya fue modificada para consultar los documentos mediante `getBlob()` de Firebase Storage y las credenciales de la cuenta administradora.

Consulta **`CAPACITACION_PROTECCION_FIREBASE_STORAGE.md`** para las instrucciones de activación de seguridad, carpeta exacta de los archivos, reglas y CORS.

Estado: código del repositorio actualizado. Hasta que Firebase Storage tenga los documentos, las reglas desplegadas y CORS configurado, el visor y los botones de descarga no podrán mostrar esos PDF.

Atención: si alguna versión anterior del repositorio tenía PDFs públicos, es necesario revisar también su historial de Git y las cachés; quitarlos de la rama actual no basta.
