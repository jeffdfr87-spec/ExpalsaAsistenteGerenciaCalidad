El proyecto Firebase es `oceantreasure-app`. `firebase.json` señala `firestore.rules` y los codebases de Cloud Functions `registro-inspectores` y `analisis-sabor`.

Los frontends de Distribución, Oliver e Inspecciones se alojan por separado; sus permisos de Firestore están incluidos en el conjunto activo de reglas.
